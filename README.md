# 个人博客

一个纯前端实现的个人博客，无需任何后端服务，所有数据保存在浏览器 `localStorage` 中。

## 功能

- **文章管理**：发布、编辑、删除、置顶、草稿箱、Markdown 编辑器（工具栏 + 实时预览 + 自动保存草稿）
- **内容引擎**：自研 Markdown 渲染器、代码语法高亮、自动文章目录（滚动高亮）、字数与阅读时长
- **内容发现**：分类筛选、标签云、全文搜索（`Ctrl+K`）、最新/最热排序、分页、热门文章、相关推荐
- **互动系统**：楼中楼评论回复、评论/文章点赞、浏览量、复制链接、上一篇/下一篇导航
- **用户系统**：管理员密码登录（默认 `admin123`，在 `blog.js` 顶部 `ADMIN_PASSWORD` 修改）、访客昵称记忆、博主标识
- **界面体验**：亮/暗主题、响应式移动端导航、阅读进度条、返回顶部、滚动出现动画、Toast 通知
- **数据持久化**：导出/导入 JSON 备份、恢复示例、一键清空

## 使用

直接用浏览器打开 `index.html` 即可。或本地起个静态服务：

```bash
npx serve .
```

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面骨架 |
| `blog.js` | 全部功能逻辑 |
| `style.css` | 样式（亮/暗主题、响应式、动画） |

## 调试 API

控制台可用：

- `Blog.export()` 导出数据
- `Blog.download()` 下载备份
- `Blog.reset()` 清空数据
- `Blog.posts()` 打印文章列表
- `Blog.theme()` 切换主题
